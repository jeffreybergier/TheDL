# SSH Configuration for TheDL
This folder contains an SSH private key and configuration used exclusively for this project.

## Purpose
These credentials allow the Gemini CLI agent to connect to a specific macOS Mavericks virtual machine located on a private local area network (LAN). This connection is required to compile and build the legacy components of TheDL (iPhoneOS 3.1 and Mac OS X 10.4).

## Security Note
This private key is dedicated solely to this development environment and does not provide access to any other systems or sensitive data. It is included in this repository specifically to enable the automated headless build workflow on the private VM.
